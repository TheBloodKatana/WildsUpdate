## Mac

1. Requires Java to be installed: https://www.oracle.com/java/technologies/downloads/#jdk17-mac
2. In Finder, select the folder containing this readme, and on the top bar, click on "Finder", then "Services", then select "New Terminal at Folder".
3. Enter the following commands in the terminal:

cat mac-launcher.template > mac-launcher.command
chmod +x mac-launcher.command

Play the game by double-clicking "mac-launcher.command".

## Linux
1. Check if you can run the native version first: https://github.com/SheerSt/pokewilds/releases/latest/download/pokewilds-linux64.zip
2. Requires Java to be installed: https://www.oracle.com/java/technologies/downloads/#jdk17-linux
3. Right-click on the file "linux-launcher", go on the permissions tab, and ensure that the file is executable.

Play the game by double-clicking "linux-launcher".

## Windows

1. Check if you can run the native version first: https://github.com/SheerSt/pokewilds/releases/latest/download/pokewilds-windows64.zip
2. Requires Java to be installed: https://www.oracle.com/java/technologies/downloads/#jdk17-windows

Play the game by double-clicking "pokewilds.jar".
